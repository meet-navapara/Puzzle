# PetalGrid branding

- `app_icon.png` / `app_icon_foreground.png`: launcher icon sources, 1024 px.
  Rendered from code (`PetalLogoPainter` in `lib/ui/widgets/brand_logo.dart`)
  by `flutter test test/store_assets/generate_store_assets.dart`, then
  `dart run flutter_launcher_icons`. Original artwork; no third-party assets.
- The in-app logo, wordmark and store graphics use the same painter.
- Do not use third-party game art.
