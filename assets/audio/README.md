# PetalGrid audio assets

Drop original / properly licensed files here. The app probes these paths at
startup and falls back to system clicks when a file is missing.

| File | Purpose |
|------|---------|
| `place.wav` | Valid piece placement |
| `clear.wav` | Line clear |
| `bloom.wav` | Bloom prune |
| `reject.wav` | Invalid drop / reject |
| `game_over.wav` | Garden full / game over |
| `music_loop.ogg` | Looping background music |

Do not use audio extracted from other commercial games.
